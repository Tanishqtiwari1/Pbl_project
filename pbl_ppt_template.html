    Problem Statement

    Traditional prosthetic limbs are expensive and often rely on complex EMG signals that require high effort and long training time. Many users struggle with intuitive control, especially for multi-joint movements like grasping, rotating, and lifting. This project aims to provide a low-cost, voice-based control layer that feels natural and reduces the learning curve for amputees.

    Literature Review

    Existing voice-controlled prostheses use speech ICs & microcontrollers for basic pick-and-place tasks. Bionic hands leverage voice control for grip selection across multiple degrees of freedom.

    Research Gap / Innovation

    Most systems are hardware-only with no web-based simulation. Our innovation: a browser-first voice interface with modular command mapping — ready to connect to real prosthetic hardware via microcontrollers.

    System Methodology

    Dataset / Input

    Voice commands captured in real-time using the Web Speech API from the user's microphone.

    Model / Architecture

    Voice → Speech Recognition → Node.js Backend → Prosthetic Simulation → JSON Database Logging
